# Micara for Mac — specification (Swift rewrite of the Electron bridge)

Decided on 2026-09-12 with Nicolas. The Electron bridge (`../bridge/`) stays in
place until parity; this folder then becomes the public `micara-mac` repo.
Model: Eyesaver (`PROJECTS/eyesaver`) — same shape, same style, same build.

## What the app does

1. **Install**: `git clone … && ./build.sh --install`. The script installs
   BlackHole 16ch when missing (`sudo installer -pkg`, password once), builds,
   copies into `/Applications`, starts it. Open at Login on by default.
2. **First launch**: the app calls `POST /api/device/register` (anonymous) and
   gets back a **permanent space code** plus an api token → a 0600 file
   (`TokenFile`, since the keychain asked for the password on every ad-hoc
   build). Zero login.
3. **Menu bar** (icon, no Dock, no window):
   `Start a Meeting` / `End the Meeting`, `Mixing ▸ Dominance + gate | Sum`,
   `Open at Login`, `Reinstall the Micara Microphone`, `Check for Updates`,
   `Share Micara`, `Star on GitHub`, `Quit`.
4. **Start a Meeting**:
   - `ensure` the "Micara" CoreAudio aggregate (UID
     `com.getmicara.bridge.aggregate`, sub-device `BlackHole16ch_UID`);
   - remember the current default microphone, force "Micara";
   - connect the WS `wss://app.getmicara.com/ws?token=…&role=bridge`;
   - a **steady, thin blue** border on every display (click-through);
   - a bar at the bottom, a non-activating `NSPanel`, Eyesaver style.
5. **Bar**: logo · mix VU meter · one dot per phone (green connected, orange
   reconnecting, gone after 30 s without a return) · `Mute` / `Unmute` ·
   `End`. **Hover** → the QR code unfolds above it with the Eyesaver
   animation. QR = `https://app.getmicara.com/r/<code>`, generated by
   `CIQRCodeGenerator`, rounded modules, no white background.
6. **Mute**: the phones stop going into BlackHole (gain 0, locally). No server
   message, so the phones cannot unmute themselves. The Mac's microphone keeps
   going.
7. **End**: closes the peers and the WS, restores the default microphone from
   before, hides the bar and the border. The phones see the bridge leave and
   retry on their own (the current PWA behaviour).

## Audio

```
phone n ─WebRTC─▶ PCM 48 kHz ─▶ gate+dominance ─┐
Mac microphone (AVAudioEngine, AEC) ────────────┴─▶ mix ─▶ limiter ─▶ BlackHole 16ch (ch 1-2)
                                                              └─▶ the bar's VU meter
```

- The "Micara" aggregate exists only for the **name** seen in Teams/Zoom. It
  wraps BlackHole and nothing else: the Mac's microphone is mixed **in
  software**, as it is today (`engine.js`, `LOCAL_ID`). Why: an aggregate
  concatenates channels, and Teams would only take the first two.
- "Dominance + gate" mixing = a 1:1 port of `bridge/renderer/mixer.cjs` with
  the constants from `MIX` (gate −45/−50 dBFS, hold 400 ms, duck −18 dB,
  margin 3 dB, dwell 300 ms, attack 50 ms, release 300 ms, tick 50 ms, input
  gain +10 dB). "Sum" = gains at 1, limiter only.
- Output to BlackHole: an `AVAudioEngine` whose `outputNode` is pinned to the
  BlackHole device (`kAudioOutputUnitProperty_CurrentDevice`). Never the
  system default device.
- WebRTC reception: `LiveKitWebRTC.xcframework` (LiveKit fork 150.7871.02,
  `LKRTC…` symbols). Chosen after a spike: the Google "stasel" build does not
  expose the PCM of remote tracks; LiveKit's has
  `LKRTCAudioTrack.addRenderer` → an `AVAudioPCMBuffer` per track, plus a
  steerable ADM (`outputDevice`) as plan B. Downloaded by `curl` into
  `Vendor/` (gitignored) and linked as a local `binaryTarget`: SwiftPM fails
  to download as soon as the keychain holds several github.com identities (the
  multi-account `gh` case).
- Microphone permission (TCC) asked at the first meeting. The ad-hoc signature
  changes on every build → asked again after every reinstall. Acceptable.

## Server protocol (unchanged but for one route)

Bridge WS: `welcome{space.secretCode, iceServers}`, `phone-joined{phoneId}`,
`phone-left{phoneId}`, `offer{sdp,phoneId}` → `answer`, `ice` both ways.
The app still sends `stream-state{phoneId,live}` (useful in the server logs);
`speaking` is no longer emitted (there is no participant dashboard any more).
Heartbeat `POST /api/bridge/heartbeat {version, state}` every 30 s, as before.

**New (done, tested)**: `POST /api/device/register` → `{ token, code, space }`.
Every Mac is a ghost user `device-<id>@micara.local` (a random password that is
never handed out): zero schema change, and the super admin dashboard counts
installs. Token `kind='api'`. Abuse control: `authLimiter`. Test:
`server/test-device-register.js`.

## Updates

Like Eyesaver: one request a day to the GitHub releases of
`GNRNicolas/micara-mac`. The difference: `Update` runs
`git pull && ./build.sh --install` in the original checkout, whose path
`build.sh --install` wrote down (`defaults write com.getmicara.mac
sourcePath`), and the script restarts the app. With no known checkout (app
copied by hand), the release page opens instead.

## Shape of the code

A SwiftPM package (forced by the binary dependency), macOS 13 target, arm64
first. Files:

| File | Job |
|---|---|
| `Sources/Micara/main.swift` | AppDelegate, menu, meeting cycle |
| `Sources/Micara/App.swift` | `Settings`, `AppLog` |
| `Sources/Micara/Account.swift` | anonymous registration, code, token (0600 file), heartbeat |
| `Sources/Micara/Updater.swift` | GitHub check plus the update through the script |
| `Sources/Micara/Style.swift` | colours, geometry (Eyesaver + a blue `accent`) |
| `Sources/Micara/Bar.swift` | pill, dots, VU meter, QR on hover (from Eyesaver) |
| `Sources/Micara/Borders.swift` | one border per display (from Eyesaver, blue, thin, no pulse) |
| `Sources/Micara/Aggregate.swift` | port of `micara-audio.c`: list/status/ensure/remove |
| `Sources/Micara/Audio.swift` | AVAudioEngine, local microphone, BlackHole output, VU meter |
| `Sources/Micara/Signal.swift` | WebSocket plus the WebRTC peers, dot states |
| `Sources/MicaraCore/Mixer.swift` | `DominanceMixer`, pure, no AppKit |
| `Sources/MicaraCore/Protocol.swift` | WS messages, Codable |
| `Sources/MicaraCore/PhoneRoster.swift` | dot states (green / orange / ghost for 30 s) |
| `Tests/MicaraCoreTests/` | mixing (the cases of `test-mixer.mjs`), protocol |
| `build.sh` | Eyesaver + BlackHole + `swift build -c release` |
| `Resources/` | `icon.png` (1024, from the bridge), `tray-gray*.png`, `BlackHole16ch-0.7.1.pkg`, GPL-3.0 |
| `Vendor/` | `LiveKitWebRTC.xcframework`, downloaded by `build.sh`, gitignored |

Colours: a blue border and accent (the value to be settled with the logo),
Eyesaver's ink/night for everything else. The whole style inherits Eyesaver's
`PillBackground`, `PillButton` and `Borders`.
